# HisabKit

**The operating system for MSME finance workflows.**

HisabKit is a multi-tenant SaaS platform that helps small businesses replace paper registers, WhatsApp notes, and ad-hoc spreadsheets with a structured, auditable ledger system. It runs across web and mobile with shared business rules and a single source of truth.

---

## What You Can Do With HisabKit

| Capability | Description |
|---|---|
| **Customer Ledger** | Ledger-first customer records with full transaction history |
| **Balance & Portfolio Visibility** | Real-time exposure across all customers |
| **Transaction Recording** | Sales, payments, and corrections with audit trails |
| **Reminders & Follow-Up** | Structured dunning and settlement workflows |
| **Analytics & Exports** | Aging analysis, BI hub, and CSV/Excel data extracts |
| **Role-Safe Admin Controls** | Multi-tenant isolation, audit logs, and privileged operations |

## Documentation Principles

- **One topic, one place.** No duplication between files.
- **Standards define the target**, not the current state. Gaps are tracked in the Changelog.
- **Every change is traceable.** The Changelog captures what changed, why, and which quality gates passed.
- **Docs update with the code.** If a change affects contracts, architecture, or standards, docs update in the same change set.
- **Legacy material lives in `archive/`.** Never in the active navigation path.
